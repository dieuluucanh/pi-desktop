# Pi Desktop — parity with terminal Pi

**Last updated:** 2026-10-26 (session parity: transcript, run control, commands, share/bug, keymap).

This matrix is the product's contract: Pi Desktop is the desktop UI for the Pi
coding agent, and every row is either **implemented**, **planned at a stated
step**, or an explicit **non-goal**. "Terminal Pi" means the `pi` CLI running
from `@earendil-works/pi-coding-agent` 1.4.0.

Status legend: ✅ implemented · 🚧 planned (step) · ⛔ deliberately out of scope.

> **Session-chat details** (transcript, composer, queue, bash, find, commands,
> keybindings, updates) are tracked in
> [architecture/session-parity.md](../architecture/session-parity.md). The rows
> marked 🚧 below have a numbered step in that document.
